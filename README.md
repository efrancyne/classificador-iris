# Classificação de Espécies de Flores com KNN

## Sobre o Projeto

Este projeto tem como objetivo classificar espécies de flores utilizando o algoritmo K-Nearest Neighbors (KNN) e o dataset Iris.

## Dataset

O conjunto de dados Iris possui:

- 150 amostras
- 3 espécies de flores
- 4 atributos numéricos

## Tecnologias

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-Learn

## Etapas Realizadas

- Análise exploratória dos dados (EDA)
- Tratamento e visualização dos dados
- Divisão em treino e teste
- Treinamento do modelo KNN
- Avaliação por acurácia e matriz de confusão

## Resultados

O modelo apresentou alta acurácia na classificação das espécies do dataset Iris.
